# TUF Price Tracker

A Python project developed to collect, store, analyze, and visualize the price history of an ASUS TUF laptop.

## Features

- Automated price scraping
- Price history storage
- Historical price analysis
- Highest and lowest price tracking
- Average price calculation
- Price variation calculation
- Price history visualization
- Analysis execution counter

## Project Structure

tuf-price-tracker/
├── main.py
├── scraper.py
├── resultado_scraper.json
├── storage.py
├── analytics.py
├── visualization.py
├── qty_analysis.txt
├── log/
└── analysis/

## Files and Functions

### main.py

Main entry point of the project. It coordinates the execution of the different modules and runs the project workflow.

### scraper.py

Responsible for accessing the product page and collecting the available price information. The collected data is saved to resultado_scraper.json.

### resultado_scraper.json

Acts as the bridge between scraper.py and storage.py. The scraper writes the collected information to this file, while storage.py reads it to process and store the data.

### storage.py

Responsible for processing the data generated by the scraper and storing the price records in the log/ directory.

### analytics.py

Responsible for analyzing the stored price history.

It calculates information such as:

- Highest price
- Lowest price
- Average price
- Price variation
- Historical price data

The generated analysis results are stored in the analysis/ directory.

### visualization.py

Responsible for generating a graphical representation of the collected price data using the analysis results.

### qty_analysis.txt

Stores the number of analyses performed by the project. The file contains only an integer value, which is incremented each time an analysis is executed.

### log/

Contains the historical price records collected by the project.

### analysis/

Contains the analysis results generated from the stored price history.

## Data Flow

The project follows this workflow:

scraper.py → resultado_scraper.json → storage.py → log/ → analytics.py → analysis/ → visualization.py

The qty_analysis.txt file keeps track of the number of analysis executions.

## Requirements

- Python 3.x
- BeautifulSoup
- Matplotlib

## How to Run

Run the main script:

python main.py

## Important

All Python files must remain in the same parent folder for the project to work correctly.

The log/ and analysis/ directories must also remain available.

If the project files are moved to different directories, the file paths used by the project may need to be updated.
